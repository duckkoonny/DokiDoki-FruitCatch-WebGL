# Doki Doki Fruit Catch

[Play in your browser](https://duckkoonny.github.io/DokiDoki-FruitCatch-WebGL/)

## Controls

- **Keyboard** — A/D or Left/Right to move, W/Up to jump, S/Down to drop faster, and Shift with a direction to dash. Adjust the magnet in Settings.
- **Joystick / Gyro** — In desktop Chrome or Edge, open **Sensors → Choose COM port** and select the ESP32. Close any Serial Monitor or desktop game using that port. Select Joystick or Gyro on the game setup screen. An ultrasonic distance reading controls the magnet. Tap Piezo for a shockwave in Joystick mode.
- **Camera** — Download the Windows camera helper from Sensors. Follow its README, then click **Connect camera** and select Camera on the game setup screen. Allow local network access if prompted. The camera uses Wi-Fi and the helper processes video on your computer.

Artwork and audio retain their original creators' rights. This repository contains the compiled game and its browser sensor connector.
