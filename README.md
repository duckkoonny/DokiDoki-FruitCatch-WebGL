# Doki Doki Fruit Catch

[Play in your browser](https://duckkoonny.github.io/DokiDoki-FruitCatch-WebGL/)

Unity WebGL browser build. Use A/D or arrow keys to move, W/Up to jump, S/Down to fall faster, and Shift with a direction to dash. Adjust Magnet in Settings. Desktop browser recommended.

Artwork and audio retain their original creators' rights. This repository contains the compiled game for web distribution.
